# Предиктивное качество проката — предсказание дефектов

## Цель
Разработать систему предсказания дефектов поверхности проката на основе данных
датчиков (температура, давление, скорость) и камер визуального контроля.
Снизить долю брака на 15–20%.

## Заказчик
Краснов Виктор — начальник цеха №3.

## Исходные данные
- **OPC-сервер**: температура, давление, скорость валков — 50+ параметров, 1 Гц
- **MES**: результаты контроля качества, марки стали, режимы прокатки
- **Камеры**: 4 камеры визуального контроля на выходе стана
- Период: 12 месяцев исторических данных (~2 млн записей)
- Качество: ожидаются пропуски в OPC (~5%), разметка дефектов неполная

## Требования к результату
- **Целевая метрика**: F1-score > 0.85 на hold-out тесте
- **Латентность**: предсказание за < 500мс (real-time)
- **Формат выхода**: REST API (FastAPI) + дашборд Grafana
- **Интеграция**: в MES через API-шлюз IT-отдела

## Ограничения
- Модель должна работать на сервере без GPU (инференс на CPU, ONNX Runtime)
- Данные не выходят за периметр предприятия
- Обучение допускается на GPU-сервере DS-отдела

## Риски
- Задержки с доступом к OPC (зависимость от IT/OT) → митигировано, доступ получен
- Неполная разметка дефектов → частично решено: дополнительная разметка с ОТК
- Модель CV требует GPU для обучения → обучение на DS-сервере, инференс на CPU
