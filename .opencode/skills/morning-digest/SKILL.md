# Утренний дайджест

## Источники данных

1. `data/projects.json` — дедлайны, прогресс
2. `data/leader_tasks.json` — задачи на сегодня
3. `data/delegated_tasks.json` — чекпоинты и просрочки
4. `data/day_plan.json` — текущий план дня
5. `data/workload.json` — перегрузки команды

## Структура дайджеста

### 1. СОБЫТИЯ
- Проекты с дедлайном ≤ 3 дня
- Завершённые вчера задачи / проекты
- Новые ТЗ, ожидающие оценки
- Запланированные встречи

### 2. ЗАДАЧИ НА СЕГОДНЯ
Сгруппированы по типам:
- DEEP WORK блоки (утро)
- QUICK пакет (мелочи)
- COMMUNICATION окна (звонки/встречи)

С итогом: `X мин / 288 мин (Y% лимита)`

### 3. ДЕЛЕГИРОВАНИЯ
- 🔔 Чекпоинты на сегодня
- 🔴 Просроченные задачи
- ✅ Завершённые вчера (для информации)

### 4. АЛЕРТЫ
- 🔴 Критичное (перегрузка, просрочка, блокер)
- 🟡 Внимание (приближающийся дедлайн, высокая загрузка)

## Триггер
Вызывается при сообщениях: «доброе утро», «привет», «начнём день», «что сегодня».
