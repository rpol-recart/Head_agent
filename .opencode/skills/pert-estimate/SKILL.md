# PERT-оценка трудозатрат

## Формула

```
Expected = (Optimistic + 4 × Realistic + Pessimistic) / 6
```

## Как использовать

### Для каждой подзадачи проекта:

1. **Оптимистичная (O)** — если всё пойдёт идеально: данные чистые, требования ясны, технология знакомая
2. **Реалистичная (M)** — наиболее вероятный сценарий с учётом типичных задержек
3. **Пессимистичная (P)** — если возникнут проблемы: плохие данные, неясные требования, новая технология

### Калибровка по истории

Перед оценкой проверь историю аналогичных проектов:
- CV-задачи: коэффициент ×1.25 (обычно +25% к оценке)
- NLP: коэффициент ×1.10
- Табличные данные: коэффициент ×1.05
- С внешними зависимостями по данным: коэффициент ×1.20

### Пример расчёта

```
Подзадача: Сбор и анализ данных
  O = 16ч (данные доступны, формат понятен)
  M = 24ч (нужна очистка, несколько итераций)
  P = 40ч (данные в плохом состоянии, доступ задерживается)

  PERT = (16 + 4×24 + 40) / 6 = 25.3ч

  С калибровкой ×1.20 (внешние данные): 25.3 × 1.20 = 30.4ч
```

## Формат вывода

```
Декомпозиция:
1. <подзадача>  O=<X>ч  M=<Y>ч  P=<Z>ч  → PERT: <E>ч
2. <подзадача>  O=<X>ч  M=<Y>ч  P=<Z>ч  → PERT: <E>ч
...
Итого: <sum_O>ч (оптим.) → <sum_PERT>ч (ожид.) → <sum_P>ч (пессим.)
Калибровка: ×<factor> → скорректированная оценка: <E×factor>ч
```
