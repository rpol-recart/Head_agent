# Конвертация документов

Скилл для чтения внешних документов (docx, xlsx) и экспорта markdown-артефактов в docx.

## Доступные команды

Все команды выполняются через `scripts/docconv.py`:

### 1. Чтение .docx → markdown

```bash
python3 scripts/docconv.py read-docx <путь_к_файлу.docx>
```

Извлекает текст, заголовки, списки и таблицы из Word-документа.
Вывод в stdout в формате markdown — можно сохранить как артефакт.

**Когда использовать:**
- Руководитель говорит: «прочитай / открой / посмотри <файл>.docx»
- Получен docx-документ (ТЗ, отчёт, протокол) для импорта в систему

**Workflow импорта docx:**
1. Прочитать docx через `read-docx`
2. Показать содержимое руководителю
3. По запросу — создать артефакт (скилл `artifact-manage`) на основе извлечённого текста

### 2. Чтение .xlsx → markdown-таблицы

```bash
python3 scripts/docconv.py read-xlsx <путь_к_файлу.xlsx> [имя_листа]
```

Извлекает данные из Excel: все листы или конкретный лист.
Вывод — markdown-таблицы с заголовками.

**Когда использовать:**
- Руководитель говорит: «покажи данные из <файл>.xlsx»
- Нужно проанализировать табличные данные из Excel
- Импорт данных о загрузке, плане, бюджете из Excel

**Workflow импорта xlsx:**
1. Прочитать xlsx через `read-xlsx`
2. Показать данные руководителю
3. По запросу — обновить `data/*.json` на основе извлечённых данных

### 3. Конвертация .md → .docx

```bash
python3 scripts/docconv.py md-to-docx <путь_к_файлу.md> [путь_выхода.docx]
```

Конвертирует markdown-артефакт в Word-документ (через pandoc).
Если путь выхода не указан — создаёт файл с тем же именем и расширением `.docx`.

**Когда использовать:**
- Руководитель: «экспортируй ТЗ в docx», «сделай ворд из отчёта»
- Нужно отправить документ внешнему заказчику / руководству
- Формальное согласование требует формата docx

**Рекомендуемые пути экспорта:**
- ТЗ → `data/artifacts/tz/<id>.docx`
- Отчёты → `data/artifacts/reports/<id>.docx`

### 4. Конвертация .md → .pdf (опционально)

```bash
python3 scripts/docconv.py md-to-pdf <путь_к_файлу.md> [путь_выхода.pdf]
```

Требует установленный pdflatex. Может быть недоступно.

## Зависимости

- `python3` + `python-docx` (чтение docx)
- `python3` + `openpyxl` (чтение xlsx)
- `pypandoc-binary` (конвертация md→docx, md→pdf, включает pandoc)
