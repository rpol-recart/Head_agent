# Еженедельный отчёт

## Источники данных

1. `data/projects.json` — прогресс за неделю
2. `data/workload.json` — загрузка каждого сотрудника
3. `data/delegated_tasks.json` — статус делегированных задач
4. `data/leader_tasks.json` — выполненные/отложенные задачи руководителя
5. `data/calibration.json` — точность оценок

## Разделы отчёта

### 1. ПРОГРЕСС ПРОЕКТОВ
ASCII-бары прогресса, дедлайны, отклонения от плана.

### 2. ЗАГРУЗКА КОМАНДЫ
Таблица с барами: кто загружен, кто свободен, рекомендации.

### 3. ДЕЛЕГИРОВАНИЯ
- В работе / завершено / просрочено за неделю
- Среднее отклонение от оценки

### 4. ЗАДАЧИ РУКОВОДИТЕЛЯ
- Выполнено / перенесено / делегировано
- % заполнения дней (vs 60% лимит)
- Сколько незапланированного попало в буфер

### 5. ВЫВОДЫ И РЕКОМЕНДАЦИИ
- Основные риски на следующую неделю
- Предложения по перераспределению нагрузки
- Задачи, требующие внимания руководителя
