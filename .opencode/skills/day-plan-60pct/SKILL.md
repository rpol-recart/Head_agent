# Правило 60% — план дня руководителя

## Константы

```
РАБОЧИЙ ДЕНЬ     = 480 мин (8 часов)
ЛИМИТ 60%        = 288 мин (4ч 48мин) — максимум запланированных задач
БУФЕР 40%        = 192 мин (3ч 12мин) — резерв на незапланированное
```

## Алгоритм формирования дня

### Шаг 1 — Собери задачи
Из `data/leader_tasks.json` возьми все со статусом `pending` или `scheduled`.

### Шаг 2 — Отсортируй по приоритету
P0 → P1 → P2 → P3 (внутри приоритета — по дедлайну).

### Шаг 3 — Размести по блокам

```
УТРО (09:00–12:00) — приоритет DEEP_WORK
  • Блоки 1.5–2ч без прерываний
  • Максимум 2 блока deep work утром

СЕРЕДИНА ДНЯ (10:30–11:00 или 12:00–13:00) — QUICK
  • Пакеты мелких задач по 30 мин
  • Все quick задачи в один пакет

ПОСЛЕ ОБЕДА (13:00–17:00) — COMMUNICATION
  • Звонки, встречи, переписка
  • Группировать рядом, чтобы не разрывать deep work

ВЕЧЕР (15:00–17:00) — можно ещё 1 блок DEEP_WORK
  • Если утром не вместилось
```

### Шаг 4 — Проверь лимит 60%

```
total_planned = sum(все слоты кроме буфера)

ЕСЛИ total_planned ≤ 288 мин:
  ✅ План в рамках лимита

ЕСЛИ total_planned > 288 мин:
  ⚠ Превышение! Предложи варианты:
  1. Перенести задачу P3/P2 на завтра
  2. Заменить менее приоритетную
  3. Делегировать сотруднику
  4. Добавить сверх лимита (предупредить о сокращении буфера)
```

### Шаг 5 — Между блоками

Добавь 15 мин перерыв между разнотипными блоками (deep_work → communication).

## Формат плана

```
План на <дата>
Загрузка: <X>ч <Y>мин / 4ч 48мин (<Z>% от лимита 60%)

┌─ DEEP WORK ──────────────────────────────────────┐
│ 09:00-10:30  <задача>              [проект]       │
└──────────────────────────────────────────────────┘
┌─ QUICK ──────────────────────────────────────────┐
│ 10:30-11:00  Пакет: <N> задач                    │
│              ✓ <задача 1>          [проект]       │
│              ✓ <задача 2>          [проект]       │
└──────────────────────────────────────────────────┘
┌─ COMMUNICATION ──────────────────────────────────┐
│ 11:00-11:30  <встреча/звонок>      [проект]      │
└──────────────────────────────────────────────────┘

░░ БУФЕР (<X>ч <Y>мин) — свободно ░░

В очереди на завтра:
- <задача> (<тип>, <приоритет>)
```
