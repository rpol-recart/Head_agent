# Проверка загрузки команды

## Источники данных

- `data/team.json` — профили сотрудников, навыки, capacity
- `data/workload.json` — текущая загрузка по сотрудникам

## Формат вывода

```
Загрузка команды (неделя <дата>):

██████████ <Имя>    <plan>/<cap>ч  (<pct>%)  — <проекты>  [статус]
```

## Пороги

| % загрузки | Бар | Статус | Рекомендация |
|-----------|-----|--------|-------------|
| ≥ 100% | ██████████ | 🔴 Перегрузка | Срочно перераспределить |
| 90–99% | █████████░ | 🟡 Высокая | Не назначать новое |
| 60–89% | ████████░░ | 🟢 Норма | Можно назначить |
| < 60% | ██████░░░░ | 🔵 Свободен | Приоритетный кандидат |

## Поиск исполнителя

При запросе «кто может взять <навык> на <X> часов»:

1. Фильтр по навыку в `data/team.json`
2. Вычисли свободные часы: `capacity - planned_hours`
3. Отсортируй по свободному времени (desc)
4. Учти уровень навыка: expert > senior > middle > junior
5. Покажи топ-3 кандидатов
